# Djurnamn på latin 🐾

En enkel, barnvänlig quiz-app där man lär sig vilket latinskt namn som hör till vilket djur.

## Användning

Öppna bara `index.html` i en webbläsare (dubbelklicka på filen) – ingen installation eller internetanslutning behövs.

## Funktioner

- **📖 Lär dig** – tryck på ett djur för att se dess latinska namn, tryck på 🔊 för att höra namnet uppläst (svenska)
- **🎮 Spela quiz** – välj rätt latinskt namn bland fyra alternativ, få stjärnor och ett resultat i slutet
- Bästa resultat sparas lokalt i webbläsaren

## Djur i appen

Guppy, Malawiciklid (Golden), Grekisk landsköldpadda, Korallfingergroda, Platy, Zebrafink, Dvärgskäggagam, Leopardgecko, Majsorm, Guldhamster, Kanin, Undulat, Gerbil, Råtta, Mus, Marsvin.
